# Lステップ顧客分類ルール

休日診断では「同行者」と「診断結果」を分けてタグ管理します。

## 共通タグ

- `休日診断_特典獲得`
- `同行者_子ども`
- `同行者_家族`
- `同行者_友人`
- `同行者_ひとり`
- `休日診断_親子わくわく`
- `休日診断_ごほうび御膳`
- `休日診断_甘味ひとやすみ`

## 自動応答設定

各ルールは次の条件で作成します。

- メッセージ種別: テキスト
- マッチ方法: 完全一致
- 応答回数: 1人1回
- アクション: 上表の3タグを追加

ユーザーは診断後に届くLINEメッセージの「診断結果をLINEに残す」をタップし、入力済みキーワードを送信します。Lステップがそのキーワードを受信して本人にタグを付けます。

## 分析例

- `同行者_子ども` + `休日診断_甘味ひとやすみ` = 子ども連れで甘味・カフェ関心
- `同行者_友人` + `休日診断_甘味ひとやすみ` = 友人利用でカフェ関心
- `同行者_ひとり` + `休日診断_ごほうび御膳` = ひとり利用で食事関心

診断結果を客層そのものと断定せず、「同行者」と「利用関心」を別軸で保持します。
